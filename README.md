# WebP 转换工具

WebP/GIF 图片格式转换工具，支持拖拽操作。

## 功能

- **转换为 GIF** - 支持静态/动画 WebP，保留帧率和循环
- **转换为 PNG** - 动图只取第一帧，大图自动缩小并保留原图
- **拆分帧** - 提取动图每一帧为单独 PNG
- **拖拽支持** - 可直接拖拽文件/文件夹到窗口
- **批量处理** - 支持同时处理多个文件

## 使用方法

1. 双击运行 `webp转换工具.exe`
2. 拖拽文件或文件夹到等待区
3. 勾选需要的转换格式
4. 点击「开始转换」

## 安装依赖（源码运行）

```bash
pip install Pillow tkinterdnd2
```
